# The Forgotten Server

**Python製の自己完結型Linux CTFシミュレーター**

The Forgotten Serverは、Pythonだけで構築した架空のLinuxサーバーを探索・攻略するCTF（Capture The Flag）形式のシミュレーターです。

プレイヤーは仮想ターミナルからLinuxコマンドを使用し、ファイルや設定を調査しながら脆弱性や設定ミスを発見し、最終的にroot権限とフラグの取得を目指します。

難易度は **HTB Easy相当** を想定しています。

> ⚠️ 本プロジェクトは完全に自己完結した架空のシミュレーションです。
> 実際のネットワークや外部システムには接続しません。

---

## 目的

放置された研究用サーバーを調査し、以下の2つのフラグを取得してください。

```text
user.txt
root.txt
```

想定される攻略の流れは、実際のLinuxペネトレーションテストで行われる基本的な流れを意識しています。

```text
情報収集
  ↓
列挙
  ↓
情報の発見
  ↓
初期アクセス
  ↓
権限昇格
  ↓
root取得
  ↓
フラグ取得
```

## 攻略について

このCTFでは、最初から明確な攻略手順が与えられるわけではありません。

ファイルシステムを探索し、発見した情報から次の行動を考えることが重要です。

例えば、

```text
ls
  ↓
cat
  ↓
設定ファイル・ログの調査
  ↓
sudo -l
  ↓
スクリプトの解析
  ↓
権限昇格
```

というように、**「情報を集めて、その情報から次の攻撃方法を考える」**ことを想定しています。

## セキュリティについて

このプロジェクトは教育目的のCTFシミュレーターです。

実際の攻撃対象に対して以下の処理を行うことはありません。

* ネットワークスキャン
* 外部ホストへの接続
* 実際のサービスへの攻撃
* 実OS上での権限昇格
* 第三者システムへのアクセス

ファイルシステム、ユーザー、権限、脆弱性、コマンドの動作はすべてPython上でシミュレーションされています。
